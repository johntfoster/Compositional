# Protected verified input blocks

Every versioned `.i` file below this directory is an immutable assembly payload.
Do not edit, replace, rename, or delete one. Use its registry ID through the
`deck-assembler` skill.

An intentional revision requires the author's explicit authorization, fresh mapped
test evidence, a higher semantic version, and the `verified-block-promotion`
skill. That workflow creates a new versioned file and preserves the earlier
payload.
