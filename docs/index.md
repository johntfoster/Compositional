# Multicomponent Reactive Flow examples

This site presents executable MOOSE examples for finite-deformation,
multiphase mixture mechanics.  Each example states the physical reduction,
maps it to residuals and material properties, records the input-deck
construction, and separates verified results from planned comparisons.

The examples are designed for two readers: a user reproducing a calculation
and an agent assembling or diagnosing a deck.  Source code, validation data,
and provenance records remain the authoritative evidence.

## Reading an example

Every example page identifies its evidence level, active physics, equations,
MOOSE objects, source inputs, command, acceptance checks, plots, and remaining
scope.  A passing one-day calculation is reported as a one-day result; it is
not promoted to a long-horizon benchmark comparison without that evidence.

See the [examples index](examples/index.md) to begin.
