\section{MOOSE implementation strategy}
\label{sec:moose_implementation_strategy}

The MOOSE implementation should be built from residual objects that map
directly to the weak forms in Section~\ref{sec:reference_solid_weak_forms}.  The
first implementation milestone is not broad feature coverage; it is one
validated residual path on the solid reference configuration.

All objects should use automatic differentiation from the start.  Non-AD helper

\subsection{Automatic-differentiation boundary}
\label{sec:ad_boundary}

The implementation should separate scalar thermodynamic differentiation from
tensorial kinematics and residual assembly.  The current MOOSE finding is that
\texttt{ADDerivativeParsedMaterial} can represent scalar Helmholtz-free-energy
closures and expose derivatives such as pressures, chemical potentials, and
selected second derivatives when the independent scalar arguments are chosen
explicitly.  That capability is useful for local thermodynamic derivatives, but
it does not remove the need for explicit AD C++ code for solid and fluid
deformation-gradient kinematics, Piola transformations, pulled-back
conversion-corrected mobility, source closures, constraint residuals,
transfer-potential evolution, transfer-work recovery, and the weak forms in
Section~\ref{sec:reference_solid_weak_forms}.

Consequently, parsed derivative materials should be treated as thermodynamic
building blocks rather than as the implementation architecture.  Kernels and
materials that compute \(\mbf F\), \(J\), \(\mbf F^{-1}\), \(\mbf W_f\),
\(\mbf v_f\), \(\mbf P^{\prime\prime}\),
\(B\bar p_EJ\mbf F^{-T}\), and the storage/source terms must retain full AD
dependence on the finite-element variables and their gradients.

This boundary gives a practical rule for the first code review: a parsed free
energy may define a scalar potential and its partial derivatives, but a MOOSE
kernel must still show exactly which weak-form term it contributes to.  If a
derivative is produced by a parsed material, the input file must document the
independent variables and the maximum derivative order requested.  If a
derivative is produced by compiled C++, the material header or source should
state the thermodynamic identity it implements.

\subsection{Primitive variables}
\label{sec:primitive_variables}

The scaffold leaves the primitive variables open.  The choice should be made by
checking which variables give a nonsingular thermodynamic Jacobian and a clean
mapping to standard reservoir limits.  Candidate sets include:
\begin{itemize}[leftmargin=*]
	\item displacement plus independent Lagrangian component masses;
	\item displacement, phase pressures, saturations, and component fractions with algebraic closures;
	\item displacement plus thermodynamic potentials and constraint multipliers.
\end{itemize}

Whichever set is chosen, materials must provide the physical quantities used in
the residuals: \(M_f^\alpha\), \(M_s\), \(\mbf W_f\),
\(\mbf P^{\prime\prime}\), \(\bar p_E\), \(B\),
\(\hat\mu_\xi^\alpha\), \(\mu_\xi^\alpha\), \(\tau\),
\(\pi_\xi^\alpha\), \(\Pi_\xi\), \(\lambda\), and \(\dot r_{(m)}\).
The transfer-work levels \(L_\xi^\alpha\) are algebraically recovered from
those outputs and the phase kinematics.  The reaction interface must expose
both the traditional affinity and, when phasewise mass is not conserved, the
transfer-work-corrected conversion coefficient.

The first reviewable implementation plan is closed only for the restricted
problem stated in Section~\ref{sec:closure_requirement}.  The broader
primitive-variable contract remains open; once chosen, it must be recorded as
the map from finite-element variables to the physical quantities appearing in
the residuals.

\subsection{Discretization defaults}
\label{sec:discretization_defaults}

The production discretization combines a continuous-Lagrange base space with a
piecewise-constant enrichment, the enriched-Galerkin (EG) pattern used by
Lee and Wheeler for two-phase flow with capillary pressure \cite{lee2018eg_twophase}.
The conforming base gives the favorable conditioning and straightforward
coupling of continuous finite elements, while the constant enrichment row
supplies the elementwise mass and volume balance that a pure continuous
discretization distributes across shared degrees of freedom: testing the
storage and flux residuals against the constant enrichment function recovers
the elementwise balance in the same manner as a lowest-order
discontinuous-Galerkin scheme.  For the SPE1 benchmark the solid
displacement field uses a quadratic Lagrange base without enrichment, the
oil-pressure and transfer-potential fields use a linear Lagrange base with a
constant enrichment and a reconstructed total pressure or total
transfer potential, and the water- and gas-saturation fields use a quadratic
Bernstein base with a constant enrichment and a reconstructed saturation
\cite{lee2018eg_twophase}.

Saturations are enriched for the same reasons as pressures: the constant
enrichment row gives local conservation, and the reconstruction of the physical
saturation from the base and enrichment degrees of freedom permits pointwise
control of the field.  The quadratic Bernstein base functions are nonnegative
and form a partition of unity, so independent lower bounds on each base
coefficient and on the enrichment, enforced by a variational inequality, yield
a reconstructed saturation that is pointwise nonnegative.  This construction
permits exact phase disappearance: where the gas phase is absent, the
independently bounded Bernstein coefficient row and its enrichment drive the
reconstructed gas saturation to zero, and the saturation fields remain within
the physically admissible range through the coefficient bounds and the
sum constraint on the reconstructed saturations.  The high-order saturation
backbones require stabilization at advancing fronts, and following the
two-phase EG reference the saturation equations receive an entropy-viscosity
stabilization that acts only where the entropy residual is active
\cite{lee2018eg_twophase}.  The enriched reconstruction also feeds the
interior-facet EG operators that connect the pressure, saturation, and
transfer-potential fields across element boundaries.

The SPE1 production path uses this Q2/CG--EG arrangement throughout:
quadratic-Lagrange solid displacement; a linear oil-pressure backbone with a
constant enrichment; quadratic Bernstein water- and gas-saturation backbones
with constant enrichments and physical reconstructed saturations; and a linear
transfer-potential backbone with a constant enrichment.  This matches the
two-phase EG formulation of Lee and Wheeler, in which pressure and saturation
are enriched together in the same EG space \cite{lee2018eg_twophase}.  The
choices of Bernstein basis, independent coefficient bounds, and identity
reconstruction for the gas saturation are documented in the production input
deck and map to the traceability record in
Section~\ref{sec:traceability_rules}.

\subsection{Traceability rules}
\label{sec:traceability_rules}

Each eventual MOOSE object should cite the controlling equation in this paper
and the corresponding equation or section in the theory manuscript.  Each input
deck should state the reduction it exercises: compositional flow, black-oil
limit, poromechanics, reaction-only conversion, phase equilibrium, or a coupled
benchmark.  Generated exodus output is not validation by itself; every
verification case needs an observable, a reference result, and a tolerance.
