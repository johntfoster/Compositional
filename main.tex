\section{Introduction}
\label{sec:intro}

Multicomponent reactive flow in deforming porous media requires careful extension of the single-component phase framework to avoid trajectory ambiguities for individual chemical species. As you noted, components can transfer between phases, lacking a unique material path, while phases themselves follow distinct trajectories (e.g., solid skeleton $\mbf{v}_s$, fluid $\mbf{v}_f$). To align with the reference paper's structure---which derives material-form balances via Hamilton's principle for each phase---we adopt option 1: treat phases as pseudo-components with dedicated reference configurations $J_\alpha$, $\mbf{F}_\alpha = \mbf{A}_\alpha \bar{\mbf{F}}_\alpha$, and enforce component partitioning $\rho_\beta^\alpha = \phi_\alpha \bar{\rho}_\alpha Y_\alpha^\beta$ algebraically.

This resolves the ambiguity: phase balances are Lagrangian (material derivatives along $\mbf{v}_\alpha$), while species are Eulerian within phases but constrained by phase-level stoichiometry. The overall mass constraint $\sum_\alpha c_\alpha^+ = 0$ holds at the phase level, with $c_\alpha^+ = \sum_\beta \hat{m}_\beta^\alpha$ where $\hat{m}_\beta^\alpha$ is the net mass transfer of component $\beta$ into phase $\alpha$. For the fluid phase, this allows multicomponent advection-diffusion superimposed on the phase flux $\mbf{w}_f$, with reactions like dissolution/precipitation adjusting $Y_f^\beta$ and $c_f^+$.

The reference four-phase model (solid reactant $A$, product $B$, fluid $f$, gas $g$) extends naturally, with incompressibility $\alpha_\alpha = J_\alpha$, $\bar{J}_\alpha \equiv 1$ for solids. Capillary pressure splits $\bar{p}_f$ and $\bar{p}_g$ as before, bounding fluid pressure in partial saturation. The fluid relative flux retains $c_f^+ \nabla \tau$, now with $c_f^+ = \sum_\beta \hat{m}_\beta^f$, leading to per-component controls
\begin{equation}
  \varepsilon_\beta = \frac{|\hat{m}_\beta^f \nabla \tau|}{\phi_f Y_f^\beta |\nabla \bar{p}_f|}.
  \label{eq:epsilon_beta}
\end{equation}

This appendix-like extension derives the generalized variational principle, phase balances, and weak forms compatible with MOOSE.

  \int_{\mc{B}_0} \rho_{\xi 0}^\alpha + c^\alpha_\xi {\rm d}V_\xi^\alpha &= \int_{\mc{B}} \rho_\xi^\alpha {\rm d}v \notag \\
  \int_{\mc{B}_0} \rho_{\xi 0}^\alpha + c^\alpha_\xi {\rm d}V_\xi^\alpha &= \int_{\mc{B}} \rho_{\xi}^\alpha J_\xi {\rm d}V_\xi \notag \\
  \int_{\mc{B}_0} \rho_{\xi 0}^\alpha + c^\alpha_\xi {\rm d}V_\xi^\alpha &= \int_{\mc{B}} \rho_\xi^\alpha \frac{ J_\xi}{\eta^{\alpha}_\xi} {\rm d}V^\alpha_\xi
\end{align}

where
\begin{equation}
  \eta^\alpha_\xi = \frac{{\rm d}V_\xi^\alpha}{{\rm d}V_\xi}
  \label{eq:eta}
\end{equation}

We emphasize that $\eta_\xi^\alpha$ is defined in the \emph{reference configuration}. This choice is natural for the present variational framework because the composition constraint $\sum_\alpha \eta_\xi^\alpha = 1$ and the mass exchange terms $c_\xi^\alpha$ are both posed per unit component reference volume. Moreover, the species within a given phase are assumed to be \emph{miscible} and therefore share a single phase motion $\chi_\xi$, deformation gradient $\mbf{F}_\xi$, and Jacobian $J_\xi$. If one instead defined $\eta_\xi^\alpha$ as a current-configuration volume fraction ${\rm d}v_\xi^\alpha/{\rm d}v_\xi$, then pulling that quantity back to the reference configuration would require separate constituent-level Jacobians or motions for each species, which is contrary to the intended miscible phase description. The reference measure~\eqref{eq:eta} should therefore be understood as an internal compositional label attached to a phase material parcel, while the corresponding current partial densities are obtained only after push-forward through the common phase kinematics.

$\eta_\xi^\alpha$ is the Lagrangian (reference-configuration) volume fraction of component $\alpha$ within phase $\xi$. It labels material parcels of phase $\xi$ by their initial volumetric composition. Its thermodynamic conjugate is the partial pressure of component $\alpha$ within phase $\xi$, and the Euler–Lagrange equation for $\delta\eta_\xi^\alpha$ is the reference-configuration statement of partial pressure equilibration, which upon push-forward to the current configuration recovers the equal-fugacity condition of classical phase equilibrium thermodynamics. For a cubic EOS such as Peng–Robinson, this E–L equation is an algebraic constitutive closure that determines the partial molar volumes; for non-equilibrium diffusion, it becomes a relaxation equation toward the EOS-determined equilibrium state.

  \frac{D_\xi}{Dt}\left(\phi_\xi \bar\rho_\xi^\alpha \right)  + \left(\phi_\xi \bar\rho_\xi^\alpha \right) \nabla_\mbf{x} \cdot \mbf{v}_\xi &= \eta^\alpha_\xi \frac{\dot{c}^\alpha_\xi}{J_\xi} + \phi_\xi \bar\rho_\xi^\alpha \frac{\dot{\eta}^\alpha_\xi}{\eta^\alpha_\xi}

\end{align}

  \frac{\partial}{\partial t}\left(\phi_\xi \bar\rho_\xi^\alpha \right)  +  \nabla_\mbf{x} \cdot \left(\phi_\xi \bar\rho_\xi^\alpha \mbf{v}_\xi \right) = \eta^\alpha_\xi \frac{\dot{c}^\alpha_\xi}{J_\xi} + \phi_\xi \bar\rho_\xi^\alpha \frac{\dot{\eta}^\alpha_\xi}{\eta^\alpha_\xi} 
  \label{eq:spatial_mass}
\end{align}
%
We use the material time derivative of a quantity $\square_\xi$ following the velocity of component $\zeta$,
\[
  \frac{D_\zeta \square_\xi}{Dt} = \frac{\partial \square_\xi}{\partial t}+\mbf{v}_\zeta\cdot\nabla_{\mbf{x}}\square_\xi,
\]
and use the shorthand notation $\dot\square_\xi = D_\xi \square_\xi/Dt$ for the derivative following component $\xi$.
%

Summing over $\alpha$ gives the phase mass balance
%
\begin{align}
  \frac{\partial}{\partial t}\left(\phi_\xi \bar\rho_\xi \right)  +  \nabla_\mbf{x} \cdot \left(\phi_\xi \bar\rho_\xi  \mbf{v}_\xi \right) = \sum_\alpha \left(\eta^\alpha_\xi \frac{\dot{c}^\alpha_\xi}{J_\xi} + \phi_\xi^\alpha \bar\rho_\xi\frac{\dot{\eta}^\alpha_\xi}{\eta^\alpha_\xi}\right)
  \label{eq:spatial_mass}
\end{align}
%
where the phase densities are
\[
  \bar\rho_\xi = \sum_\alpha \bar\rho^\alpha_\xi,
\]
and from \eqref{eq:eta}, notice that the $\eta^\alpha_\xi$ form a partition of unity
\[
  \sum_\alpha \eta^\alpha_\xi = \sum_\alpha \frac{{\rm d}V^\alpha_\xi}{{\rm d}V_\xi} = \frac{{\rm d}V_\xi}{{\rm d}V_\xi} = 1.
\]

Summing over all phases gives the overall mixture mass balance
%
\begin{align}
  \underbrace{\frac{\partial \rho}{\partial t}  + \nabla_\mbf{x} \cdot \left(\rho  \mbf{v} \right)}_{=0} = \sum_\xi \sum_\alpha \left(\eta^\alpha_\xi \frac{\dot{c}^\alpha_\xi}{J_\xi} + \phi_\xi \bar\rho^\alpha_\xi \frac{\dot{\eta}^\alpha_\xi}{\eta^\alpha_\xi}\right) 
  \label{eq:overall_mass}
\end{align}
%
where $\rho = \sum_\xi \phi_\xi \bar\rho_\xi$ and the mixture velocity $\mbf{v}$ is baryicentric velocity
%
\[
  \mbf{v} = \frac{1}{\rho} \sum_\xi \rho_\xi \mbf{v}_\xi.
\]
%
Recognizing the left-hand side of \eqref{eq:overall_mass} must vanish because the right hand side is a statement of convervation of mass for the mixture, leaves
%
\begin{align}
  \sum_\xi \sum_\alpha \left(\eta^\alpha_\xi \frac{\dot{c}^\alpha_\xi}{J_\xi} + \phi_\xi \bar\rho_\xi^\alpha \frac{\dot{\eta}^\alpha_\xi}{\eta^\alpha_\xi}\right) = 0
  \label{eq:overall_mass_constraint}
\end{align}
%
as a statement of conservation of mass of the entire mixture.  This means that mass reactions and phase transitions amoung psuedocomponents in the mixture do not create nor destory mass.

\section{Using a Standard Equation of State in the Present Framework}
\label{sec:eos_appendix}

This appendix explains how a standard fluid equation of state (EOS) can be used within the present reacting-mixture framework. The key point is that our constitutive variables are adapted to mixture kinematics, whereas standard thermodynamic models are usually written in terms of partial densities, mole fractions, mass fractions, molar volume, and temperature. The two descriptions are fully compatible.

\subsection{Constitutive variables in the present theory}

For a mobile phase $\xi$, let $\eta_\xi^\alpha=\eta_\xi^\alpha(\mbf{X}_\xi)$ denote the fraction of the \emph{phase reference volume} assigned to species $\alpha$, so that
\begin{equation}
  \sum_{\alpha=1}^N \eta_\xi^\alpha = 1.
\end{equation}
This is a reference-configuration partition variable, not a current-configuration composition variable. It is paired naturally with the production term $c_\xi^\alpha$, which also appears per unit reference volume. From the phase-component material mass balance derived in Section~\ref{sec:ref_config_YJ},
\begin{equation}
  \phi_{\xi 0}\bar\rho_{\xi 0}^\alpha + c_\xi^\alpha = \phi_\xi \bar\rho_\xi^\alpha J_\xi \eta_\xi^\alpha,
\end{equation}
so the current partial mass density per unit current mixture volume is
\begin{equation}
  \rho_\xi^\alpha = \phi_\xi \bar\rho_\xi^\alpha = \frac{\phi_{\xi 0}\bar\rho_{\xi 0}^\alpha + c_\xi^\alpha}{J_\xi\eta_\xi^\alpha}.
  \label{eq:eos_partial_density}
\end{equation}
Therefore the mobile-phase Helmholtz free energy per unit current mixture volume may still be written in the thermodynamically standard form
\begin{equation}
  \Psi_\xi = \hat\Psi_\xi(\rho_\xi^1,\dots,\rho_\xi^N,\theta_\xi),
  \label{eq:eos_free_energy_density_form}
\end{equation}
but in the present framework the arguments $\rho_\xi^\alpha$ are obtained by push-forward of the reference data through~\eqref{eq:eos_partial_density}. Equation~\eqref{eq:eos_free_energy_density_form} is still the cleanest way to embed a general EOS, but the constitutive map to its arguments must respect the reference character of $\eta_\xi^\alpha$.

\subsection{Connection to standard EOS variables}

Many equations of state are instead given in terms of mole fractions $x_\xi^\alpha$, molar volume $v_\xi$, and temperature $\theta_\xi$, through a molar Helmholtz free energy
\begin{equation}
  a_\xi = a_\xi(x_\xi^1,\dots,x_\xi^N,v_\xi,\theta_\xi).
\end{equation}
To use such a model, define the molar concentration of species $\alpha$ per unit current mixture volume as
\begin{equation}
  n_\xi^\alpha = \frac{\rho_\xi^\alpha}{M^\alpha} = \frac{\phi_{\xi 0}\bar\rho_{\xi 0}^\alpha + c_\xi^\alpha}{J_\xi\eta_\xi^\alpha M^\alpha},
\end{equation}
where $M^\alpha$ is the molar mass. The total molar concentration is then
\begin{equation}
  n_\xi = \sum_{\beta=1}^N n_\xi^\beta = \sum_{\beta=1}^N \frac{\phi_{\xi 0}\bar\rho_{\xi 0}^\beta + c_\xi^\beta}{J_\xi\eta_\xi^\beta M^\beta}.
\end{equation}
Hence the mole fractions are
\begin{equation}
  x_\xi^\alpha = \frac{n_\xi^\alpha}{n_\xi} = \frac{\rho_\xi^\alpha/M^\alpha}{\sum_{\beta=1}^N \rho_\xi^\beta/M^\beta},
  \label{eq:eos_mole_fraction_map}
\end{equation}
and the molar volume of the mobile phase is
\begin{equation}
  v_\xi = \frac{1}{n_\xi} = \left(\sum_{\beta=1}^N \frac{\rho_\xi^\beta}{M^\beta}\right)^{-1}.
  \label{eq:eos_molar_volume_map}
\end{equation}
Accordingly, a standard EOS written as $a_\xi(x_\xi^\alpha,v_\xi,\theta_\xi)$ is converted to the present variables by first evaluating the current partial densities from~\eqref{eq:eos_partial_density}, then substituting those densities into~\eqref{eq:eos_mole_fraction_map} and~\eqref{eq:eos_molar_volume_map}. The free energy per unit current mixture volume is then
\begin{equation}
  \Psi_\xi = n_\xi a_\xi = \frac{1}{v_\xi} a_\xi(x_\xi^\alpha,v_\xi,\theta_\xi),
  \label{eq:eos_transformed}
\end{equation}
with $x_\xi^\alpha$ and $v_\xi$ understood as the functions of $(\phi_{\xi0}\bar\rho_{\xi0}^\beta,c_\xi^\beta,J_\xi,\eta_\xi^\beta)$ defined above.

\subsection{Pressure and other thermodynamic quantities}

Once the EOS has been written in the form~\eqref{eq:eos_transformed}, the thermodynamic pressure of phase $\xi$ follows from the usual relation
\begin{equation}
  \bar p_\xi = -\left.\frac{\partial a_\xi}{\partial v_\xi}\right|_{x_\xi^\alpha,\theta_\xi}.
  \label{eq:eos_pressure_from_a}
\end{equation}
Likewise, chemical potentials and other thermodynamic derivatives may be taken from the same underlying EOS and then composed with the maps above. Thus the present formulation does not require a new thermodynamic theory; it requires only a change of constitutive coordinates from standard thermodynamic variables to the pulled-forward state determined by the reference variables $(\phi_{\xi0}\bar\rho_{\xi0}^\alpha,c_\xi^\alpha,J_\xi,\eta_\xi^\alpha)$.

\subsection{Practical constitutive choices}

There are two natural ways to implement a fluid EOS in this framework.

\paragraph{Option A: partial-density form.}
Take
\begin{equation}
  \Psi_\xi = \hat\Psi_\xi(\rho_\xi^1,\dots,\rho_\xi^N,\theta_\xi),
  \qquad
  \rho_\xi^\alpha = \frac{\phi_{\xi 0}\bar\rho_{\xi 0}^\alpha + c_\xi^\alpha}{J_\xi\eta_\xi^\alpha}.
\end{equation}
This is the cleanest form for analysis because it uses standard thermodynamic state variables while preserving the reference-configuration meaning of $\eta_\xi^\alpha$.

\paragraph{Option B: composition/EOS form.}
Start from a conventional EOS such as Peng--Robinson or CPA written as
\begin{equation}
  a_\xi = a_\xi(x_\xi^\alpha,v_\xi,\theta_\xi),
\end{equation}
and then use~\eqref{eq:eos_partial_density}--\eqref{eq:eos_transformed} to express it in the present variables. This is the most convenient form when one wishes to use an existing thermodynamic package or compare directly with the standard EOS literature.

For the present paper, Option A is the cleaner formal statement, while Option B is the more practical route when a specific engineering EOS is to be used explicitly.

\subsection{Single-component specialization}

For the single-fluid case used in the main body of the paper, $N=1$ and $\eta_f^1=1$, so~\eqref{eq:eos_partial_density} reduces to
\begin{equation}
  \rho_f = \phi_f\bar\rho_f = \frac{\phi_{f0}\bar\rho_{f0} + c_f}{J_f}.
\end{equation}
The EOS may therefore be written simply as
\begin{equation}
  \Psi_f = \hat\Psi_f\!\left(\frac{\phi_{f0}\bar\rho_{f0} + c_f}{J_f},\theta_f\right),
  \qquad \bar p_f = \bar p_f(\rho_f,\theta_f),
\end{equation}
or equivalently in any standard single-component form. In other words, nothing in the present theory prevents the use of a ``standard'' EOS; the only requirement is that it be evaluated using the current partial densities obtained from the underlying reference-volume description.
