\subsection{Coleman--Noll procedure for the compositional thermo-reactive mixture}
\label{sec:coleman_noll_compositional}

This subsection records the thermodynamic restrictions associated with the
constitutive specialization introduced above.  Fluid phases remain phase-level
equation-of-state phases with composition variables.  The solid phases form the
set \(\mc S\); each \(s\in\mc S\) is a one-component mineral phase with active
component label \(s\), mass fraction \(\eta_s^s=1\), and common skeleton
trajectory.  Its solid-phase kinematic split is
\(\mbf F=\mbf A_s\bar{\mbf F}_s\).  The superscript is retained because the
reaction bookkeeping still needs the phase/component pair \((s,s)\) in
\(\nu_{s (m)}^s\), \(\mu_s^s\), and \(\phasedot c_s^s\).

The Coleman--Noll calculation is applied on the reduced constitutive state space.
It is not a second derivation of the constrained equations of motion.  Constraints
that define the admissible motions and fields, such as the volume-fraction,
storage, and stoichiometric source constraints, are enforced in the variational
formulation and do not introduce additional Coleman--Noll coefficients unless a
constrained variable is an argument of a constitutive free energy.  Following
the standard Liu multiplier exploitation of constrained entropy
inequalities~\cite{liu1972method}, identically vanishing constraint-rate terms
may be added before collecting coefficients.  Fluid composition enters because
the fluid free energies depend explicitly on \(\eta_f^\alpha\); its rate is
therefore restricted to the tangent space of the mass-fraction constraint,
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\sum_\alpha\eta_f^\alpha=1,
	\qquad
	\sum_\alpha\phasedot\eta_f^\alpha=0,
	\qquad
	f\in\mc F .
	\label{eq:CN_mass_fraction_tangent_constraint}
\end{equation}
% AGENT-LOCK-END
For the solid phases, the corresponding specialization is the point constraint
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\eta_s^s=1,
	\qquad
	\phasedot\eta_s^s=0,
	\qquad
	s\in\mc S .
	\label{eq:CN_solid_composition_projected_restriction}
\end{equation}
% AGENT-LOCK-END
Thus no solid composition projection analogous to the fluid projection is left
after the one-component mineral-phase restriction.

The Coleman--Noll calculation can be written with phase-level Helmholtz
potentials for both fluid and solid phases.  For a fluid phase \(f\), let
specific entropy be denoted by \(\mathfrak{s}\):
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	e_f=\psi_f+\theta \mathfrak{s}_f,
	\qquad
	\psi_f=\psi_f(\bar\rho_f,\eta_f^\beta,\theta).
	\label{eq:CN_fluid_legendre_relation}
\end{equation}
% AGENT-LOCK-END
For each solid mineral phase, we use the phase notation \(\psi_s\) in the
thermodynamic derivation and identify it with the one active solid
phase/component potential:
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	e_s=\psi_s+\theta \mathfrak{s}_s,
	\qquad
	\psi_s=\psi_s(\bar{\mbf F}_s^e,\mbf A_s^e,\bar\rho_s,\theta).
	\label{eq:CN_solid_component_legendre_relation}
\end{equation}
% AGENT-LOCK-END
The superscripted form is retained only where the reaction bookkeeping needs the
phase/component pair \((s,s)\); the free-energy derivatives below use
\(\psi_s\).

The constitutive state sets for the solid and fluid used below are
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mc X_f=\{\bar\rho_f,\eta_f^\beta,\theta\},
	\qquad
	\mc X_s=\{\bar{\mbf F}_s^e,\mbf A_s^e,\bar\rho_s,\theta\}.
	\label{eq:CN_state_set_collection}
\end{equation}
% AGENT-LOCK-END

The held-fixed notation is used as follows:
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\left.\p{\Gamma_\xi}{z}\heldfixed{\mc X}
	\label{eq:CN_held_fixed_notation}
\end{equation}
% AGENT-LOCK-END
This denotes differentiation with respect to \(z\) while holding fixed all other
members of the state set \(\mc X\).

The dependent elastic arguments are
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mbf A_s^e
	=\mbf A_s(\mbf A_s^\theta)^{-1}(\mbf A_s^p)^{-1},
	\qquad
	\bar{\mbf F}_s^e
	=\bar{\mbf F}_s(\bar{\mbf F}_s^\theta)^{-1}
	(\bar{\mbf F}_s^p)^{-1},
	\qquad
	s\in\mc S .
	\label{eq:CN_elastic_distension_argument}
\end{equation}
% AGENT-LOCK-END
In the collection below the independent mechanical process rates are
\(\phasedot{\bar{\mbf F}}_s^e\), \(\phasedot{\bar{\mbf F}}_s^p\),
\(\phasedot{\mbf A}_s^e\), and \(\phasedot{\mbf A}_s^p\) for each \(s\in\mc S\).  The
stress-free factors
\(\bar{\mbf F}_s^\theta=\bar{\mbf F}_s^\theta(\theta)\) and
\(\mbf A_s^\theta=\mbf A_s^\theta(\theta)\) are prescribed constitutively.
The total rates \(\phasedot{\bar{\mbf F}}_s\) and \(\phasedot{\mbf A}_s\) are
reconstructed from these rates and from the stress-free thermal rates; they are
not independent Coleman--Noll rates.

Following from \eqref{eq:solid_true_mass_conservation} the density rate for a one-component solid phase is
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\frac{\phasedot{\bar\rho}_s}{\bar\rho_s}
	=-\operatorname{tr}
	\left[
		\phasedot{\bar{\mbf F}}_s^e(\bar{\mbf F}_s^e)^{-1}
		+\left.\p{\bar{\mbf F}_s^\theta}{\theta}\heldfixed{\mc X_s}
		\phasedot\theta
		(\bar{\mbf F}_s^\theta)^{-1}
		\right],
	\qquad
	\operatorname{tr}\left[
		\phasedot{\bar{\mbf F}}_s^p(\bar{\mbf F}_s^p)^{-1}
		\right]=0,
	\qquad
	s\in\mc S .
	\label{eq:CN_solid_density_rate_drumheller}
\end{equation}
% AGENT-LOCK-END
Thus \(\phasedot{\bar\rho}_s\) is not an independent solid rate. The plastic terms  vanish because the plastic deformation is isochoric.
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation*}
	\det\bar{\mbf F}_s^p=1,
	\qquad
	\operatorname{tr}\left[
		\phasedot{\bar{\mbf F}}_s^p(\bar{\mbf F}_s^p)^{-1}
		\right]=0,
	\qquad
	s\in\mc S .
\end{equation*}
% AGENT-LOCK-END

The fluid-phase free-energy rates entering the entropy inequality are
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	\sum_{f\in\mc F}\rho_f\phasedot\psi_f
	 & =\sum_{f\in\mc F}\rho_f\left(
	\left.\p{\psi_f}{\bar\rho_f}\heldfixed{\mc X_f}\phasedot{\bar\rho}_f
	+\sum_\beta\left.\p{\psi_f}{\eta_f^\beta}\heldfixed{\mc X_f}\phasedot\eta_f^\beta
	+\left.\p{\psi_f}{\theta}\heldfixed{\mc X_f}\phasedot\theta
	\right).
	\label{eq:CN_fluid_free_energy_rate}
\end{align}

For the solid phases, the one-component restriction gives
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	\sum_{s\in\mc S}\rho_s\phasedot{\psi}_s
	={} & \sum_{s\in\mc S}\rho_s \left[
		\left.\p{\psi_s}{\bar{\mbf F}_s^e}\heldfixed{\mc X_s}
		:\phasedot{\bar{\mbf F}}_s^e
		+\left.\p{\psi_s}{\mbf A_s^e}\heldfixed{\mc X_s}
		:\phasedot{\mbf A}_s^e
		\right.
	\notag                              \\
	    & \left.
		+\left.\p{\psi_s}{\bar\rho_s}\heldfixed{\mc X_s}
		\phasedot{\bar\rho}_s
		+\left.\p{\psi_s}{\theta}\heldfixed{\mc X_s}\phasedot\theta
		\right].
	\label{eq:CN_total_helmholtz_density}
\end{align}
% AGENT-LOCK-END
Substitution of \eqref{eq:CN_solid_density_rate_drumheller} supplies the
\(\phasedot{\bar{\mbf F}}_s^e\) and \(\phasedot\theta\) coefficients used below.

The fluid-phase Helmholtz energies are phase EOS potentials using the
fluid-state variables in \eqref{eq:CN_state_set_collection}.  No elastic stress power is assigned to the fluid phases, so
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\bs\sigma_f'=\mbf 0 .
	\label{eq:CN_fluid_stress_free}
\end{equation}
% AGENT-LOCK-END

The reversible interfacial energy used in the variational formulation must also
be included in the entropy bookkeeping.  The argument
\(\left\{S_f\right\}_{f\in\mc F}\) denotes the constrained fluid saturation
state defined in \eqref{eq:fluid_saturation_definitions}.  For thermal
modeling, the interfacial energy is allowed to depend on temperature
through the interfacial tension, as in the standard capillary-pressure scaling
used in reservoir engineering \cite{leverett1941capillary}.  For the fluid
phases,
%
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\psi_\gamma
	=\phi\gamma\left(\left\{S_f\right\}_{f\in\mc F},\theta\right),
	\qquad
	\phasedot\psi_\gamma
	=\sum_{f\in\mc F}\gamma_f\phasedot\phi_f
	+\phi
	\left.\p{\gamma}{\theta}\right\vert_{\left\{S_f\right\}_{f\in\mc F}}\phasedot\theta,
	\label{eq:CN_interfacial_helmholtz_rate}
\end{equation}
% AGENT-LOCK-END
where \(\gamma_f\) are the interfacial variation coefficients collected in
\eqref{eq:primitive_gamma_derivatives}, with the constrained fluid saturation
state held fixed for the temperature derivative.  The associated interfacial
entropy per current volume is
\(-\phi\,\left.\p{\gamma}{\theta}\right\vert_{\left\{S_f\right\}_{f\in\mc F}}\).


The phase energy balance is
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	\rho_\xi\phasedot e_\xi
	+\sum_\alpha\phasedot c_\xi^\alpha e_\xi
	= & \; \bs\sigma_\xi':\mbf L_\xi
	+\phi_\xi\bar p_\xi\frac{\phasedot{\bar\rho}_\xi}{\bar\rho_\xi}
	+\sum_\alpha\frac{\pi_\xi^\alpha}{\phi_\xi}\phasedot\phi_\xi
	+\sum_\alpha\frac{\pi_\xi^\alpha}{\eta_\xi^\alpha}\phasedot\eta_\xi^\alpha
	\notag                                         \\
	  & -\sum_\alpha L_\xi^\alpha\phasedot c_\xi^\alpha
	-\nabla_{\mbf x}\cdot\mbf q_\xi
	+\rho_\xi r_\xi+\rho_\xi e_\xi^{\rm int}.
	\label{eq:CN_energy_balance}
\end{align}
% AGENT-LOCK-END
For a one-component solid phase, the term
\((\pi_s^s/\eta_s^s)\phasedot\eta_s^s\) vanishes because \(\phasedot\eta_s^s=0\).

For the common solid skeleton, the mechanical power in
\eqref{eq:CN_energy_balance} must be decomposed with the same phase-specific
kinematic split used in the constitutive law.  With
\(\mbf F=\mbf A_s\bar{\mbf F}_s\),
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mbf L_s
	=\phasedot{\mbf A}_s\mbf A_s^{-1}
	+\mbf A_s\phasedot{\bar{\mbf F}}_s
	\bar{\mbf F}_s^{-1}\mbf A_s^{-1}.
	\label{eq:CN_F_split_for_power}
\end{equation}
% AGENT-LOCK-END
Using
\(\bar{\mbf F}_s=\bar{\mbf F}_s^e\bar{\mbf F}_s^p\bar{\mbf F}_s^\theta\) and
\(\mbf A_s=\mbf A_s^e\mbf A_s^p\mbf A_s^\theta\), the total solid stress power is
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	\sum_{s\in\mc S}\bs\sigma_s':\mbf L_s
	={} &
	\sum_{s\in\mc S}\operatorname{tr}\left[
		(\bs\sigma_s')^T
		\phasedot{\mbf A}_s^e(\mbf A_s^e)^{-1}\right]
	\notag                                         \\
	    & +\sum_{s\in\mc S}\operatorname{tr}\left[
		(\mbf A_s^e)^{-1}
		(\bs\sigma_s')^T
		\mbf A_s^e
		\phasedot{\mbf A}_s^p(\mbf A_s^p)^{-1}\right]
	\notag                                         \\
	    & +\sum_{s\in\mc S}\operatorname{tr}\left[
		(\mbf A_s^p)^{-1}(\mbf A_s^e)^{-1}
		(\bs\sigma_s')^T
		\mbf A_s^e\mbf A_s^p
		\left.\p{\mbf A_s^\theta}{\theta}\heldfixed{\mc X_s}
		(\mbf A_s^\theta)^{-1}\right]\phasedot\theta
	\notag                                         \\
	    & +\sum_{s\in\mc S}\operatorname{tr}\left[
	\mbf A_s^{-1}
	(\bs\sigma_s')^T
	\mbf A_s
	\phasedot{\bar{\mbf F}}_s^e(\bar{\mbf F}_s^e)^{-1}\right]
	\notag                                         \\
	    & +\sum_{s\in\mc S}\operatorname{tr}\left[
	(\bar{\mbf F}_s^e)^{-1}\mbf A_s^{-1}
	(\bs\sigma_s')^T
	\mbf A_s\bar{\mbf F}_s^e
	\phasedot{\bar{\mbf F}}_s^p(\bar{\mbf F}_s^p)^{-1}\right]
	\notag                                         \\
	    & +\sum_{s\in\mc S}\operatorname{tr}\left[
	(\bar{\mbf F}_s^p)^{-1}(\bar{\mbf F}_s^e)^{-1}
	\mbf A_s^{-1}
	(\bs\sigma_s')^T
	\mbf A_s\bar{\mbf F}_s^e\bar{\mbf F}_s^p
	\left.\p{\bar{\mbf F}_s^\theta}{\theta}\heldfixed{\mc X_s}
	(\bar{\mbf F}_s^\theta)^{-1}\right]\phasedot\theta .
	\label{eq:CN_stress_power_split}
\end{align}
% AGENT-LOCK-END

The entropy inequality is
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	0\le
	 & \sum_\xi\left[
		\rho_\xi\phasedot{\mathfrak{s}}_\xi+\sum_\alpha\phasedot c_\xi^\alpha \mathfrak{s}_\xi
		+\nabla_{\mbf x}\cdot\left(\frac{\mbf q_\xi}{\theta}\right)
		-\frac{\rho_\xi r_\xi}{\theta}\right].
	\label{eq:CN_entropy_inequality}
\end{align}
% AGENT-LOCK-END
Using \eqref{eq:CN_energy_balance} to eliminate \(\rho_\xi r_\xi\), and then
using the Legendre relations \eqref{eq:CN_fluid_legendre_relation} and
\eqref{eq:CN_solid_component_legendre_relation}, gives the reduced entropy
inequality.  We also add the identically vanishing fluid composition-normalization
rate \(\Pi_\xi\sum_\alpha\phasedot\eta_\xi^\alpha\) and the
volume-fraction-constraint rate \(\lambda\sum_\xi\phasedot\phi_\xi\).  For a
one-component solid, the corresponding rate is identically zero because
\(\phasedot\eta_s^s=0\):
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	0\le
	 & \sum_\xi
	\begin{aligned}[t]
		 & \frac{1}{\theta}\left(
		\bs\sigma_\xi':\mbf L_\xi
		+\phi_\xi\bar p_\xi\frac{\phasedot{\bar\rho}_\xi}{\bar\rho_\xi}
		+\sum_\alpha\frac{\pi_\xi^\alpha}{\phi_\xi}\phasedot\phi_\xi
		+\sum_\alpha\frac{\pi_\xi^\alpha}{\eta_\xi^\alpha}\phasedot\eta_\xi^\alpha
		\right.                                                   \\
		 & \left.
		+\Pi_\xi\sum_\alpha\phasedot\eta_\xi^\alpha
		-\rho_\xi\left(\phasedot\psi_\xi+\mathfrak{s}_\xi\phasedot\theta\right)
		-\sum_\alpha\phasedot c_\xi^\alpha
		\left(\psi_\xi+L_\xi^\alpha\right)
		+\rho_\xi e_\xi^{\rm int}\right)                          \\
		 & -\frac{\mbf q_\xi\cdot\nabla_{\mbf x}\theta}{\theta^2}
	\end{aligned}
	\notag                     \\
	 & +\frac{1}{\theta}\left(
	\lambda\sum_\xi\phasedot\phi_\xi
	-\sum_{f\in\mc F}\gamma_f\phasedot\phi_f
	-\phi\left.\p{\gamma}{\theta}\right\vert_{\left\{S_f\right\}_{f\in\mc F}}\phasedot\theta
	+\phi\left.\p{\gamma}{\theta}\right\vert_{\left\{S_f\right\}_{f\in\mc F}}\phasedot\theta
	\right).
	\label{eq:CN_reduced_entropy_inequality}
\end{align}
% AGENT-LOCK-END

Substituting the free-energy rates and the stress-power split gives the collected
solid--fluid contribution:
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	0\le\; &
	\frac{1}{\theta}\{
	\sum_{s\in\mc S}\operatorname{tr}\left[
		\left(
		(\bs\sigma_s')^T
		-\rho_s
		\mbf A_s^e
		\left(
		\left.\p{\psi_s}{\mbf A_s^e}\heldfixed{\mc X_s}
		\right)^T
		\right)
		\phasedot{\mbf A}_s^e(\mbf A_s^e)^{-1}
		\right]
	\notag                                                                      \\
	       & +
	\sum_{s\in\mc S}\operatorname{tr}\left[
	\left(
	\mbf A_s^{-1}
	(\bs\sigma_s')^T
	\mbf A_s
	-\rho_s
	\bar{\mbf F}_s^e
	\left(
	\left.\p{\psi_s}{\bar{\mbf F}_s^e}\heldfixed{\mc X_s}
	\right)^T
	+
	\left(
	\rho_s
	\left.\p{\psi_s}{\bar\rho_s}\heldfixed{\mc X_s}
	\bar\rho_s
	-\phi_s\bar p_s
	\right)\mbf I
	\right)
	\phasedot{\bar{\mbf F}}_s^e(\bar{\mbf F}_s^e)^{-1}
	\right]
	\notag                                                                      \\
	       & +
	\sum_{s\in\mc S}\operatorname{tr}\left[
		(\mbf A_s^e)^{-1}
		(\bs\sigma_s')^T
		\mbf A_s^e
		\phasedot{\mbf A}_s^p(\mbf A_s^p)^{-1}
		\right]
	\notag                                                                      \\
	       & +
	\sum_{s\in\mc S}\operatorname{tr}\left[
	(\bar{\mbf F}_s^e)^{-1}\mbf A_s^{-1}
	(\bs\sigma_s')^T
	\mbf A_s\bar{\mbf F}_s^e
	\phasedot{\bar{\mbf F}}_s^p(\bar{\mbf F}_s^p)^{-1}
	\right]
	\notag                                                                      \\
	       & +
	\left[
	-\sum_\xi\rho_\xi
	\left(
	\mathfrak{s}_\xi+\left.\p{\psi_\xi}{\theta}\heldfixed{\mc X_\xi}
	\right)
	\right. \notag                                                              \\
	       & \left.
	+\sum_{s\in\mc S}\operatorname{tr}\left[
		(\mbf A_s^p)^{-1}(\mbf A_s^e)^{-1}
		(\bs\sigma_s')^T
		\mbf A_s^e\mbf A_s^p
		\left.\p{\mbf A_s^\theta}{\theta}\heldfixed{\mc X_s}
		(\mbf A_s^\theta)^{-1}\right]
	\right. \notag                                                              \\
	       & \left.
	+\sum_{s\in\mc S}\operatorname{tr}\left[
	(\bar{\mbf F}_s^p)^{-1}(\bar{\mbf F}_s^e)^{-1}
	\mbf A_s^{-1}
	(\bs\sigma_s')^T
	\mbf A_s\bar{\mbf F}_s^e\bar{\mbf F}_s^p
	\left.\p{\bar{\mbf F}_s^\theta}{\theta}\heldfixed{\mc X_s}
	(\bar{\mbf F}_s^\theta)^{-1}\right]
	\right. \notag                                                              \\
	       & \left.
	-\phi\left.\p{\gamma}{\theta}\right\vert_{\left\{S_f\right\}_{f\in\mc F}}
	+\phi\left.\p{\gamma}{\theta}\right\vert_{\left\{S_f\right\}_{f\in\mc F}}
	\right]\phasedot\theta
	\notag                                                                      \\
	       & +\sum_{f\in\mc F}\left[
		\frac{\phi_f \bar p_f}{\bar\rho_f}
		-\rho_f
		\left.\p{\psi_f}{\bar\rho_f}\heldfixed{\mc X_f}
		\right]\phasedot{\bar\rho}_f
	-\sum_{f\in\mc F}\rho_f\sum_\beta
	\left.\p{\psi_f}{\eta_f^\beta}\heldfixed{\mc X_f}
	\phasedot\eta_f^\beta
	\notag                                                                      \\
	       & +\sum_{f\in\mc F}\sum_\beta\left(\frac{\pi_f^\beta}{\eta_f^\beta}
	+\Pi_f\right)\phasedot\eta_f^\beta
	+\sum_\xi\left(
	\lambda+\sum_\alpha\frac{\pi_\xi^\alpha}{\phi_\xi}
	\right)\phasedot\phi_\xi
	-\sum_{f\in\mc F}\gamma_f\phasedot\phi_f
	\notag                                                                      \\
	       & -\sum_m\left(
	\sum_\xi\sum_\alpha\nu_{\xi (m)}^\alpha
	\left(\psi_\xi+L_\xi^\alpha\right)
	\right) r_{(m)}
	\notag                                                                      \\
	       & +\sum_\xi\rho_\xi e_\xi^{\rm int}
	-\sum_\xi\frac{\mbf q_\xi\cdot\nabla_{\mbf x}\theta}{\theta}
	\}.
	\label{eq:CN_solid_collected_entropy}
\end{align}
% AGENT-LOCK-END

\subsubsection{Solid stress terms and pressure identifications}
The elastic true-deformation coefficient for each solid phase gives
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	\mbf A_s^{-1}
	(\bs\sigma_s')^T
	\mbf A_s
	 & =
	\rho_s
	\bar{\mbf F}_s^e
	\left(
	\left.\p{\psi_s}{\bar{\mbf F}_s^e}\heldfixed{\mc X_s}
	\right)^T
	-
	\left(
	\rho_s
	\left.\p{\psi_s}{\bar\rho_s}\heldfixed{\mc X_s}
	\bar\rho_s
	-\phi_s\bar p_s
	\right)\mbf I,
	\qquad
	s\in\mc S .
	\label{eq:CN_stress_definition}
\end{align}
% AGENT-LOCK-END
The tensor on the left is the stress power conjugate to
\(\phasedot{\bar{\mbf F}}_s^e(\bar{\mbf F}_s^e)^{-1}\).  Thus, defining the intrinsic pressure of the one-component solid phase by
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\bar p_s
	=\left(\bar\rho_s\right)^2
	\left.\p{\psi_s}{\bar\rho_s}\heldfixed{\mc X_s}.
	\label{eq:CN_component_intrinsic_pressure_definition}
\end{equation}
% AGENT-LOCK-END
The corresponding fluid phase pressure is
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\bar p_f
	=\left(\bar\rho_f\right)^2
	\left.\p{\psi_f}{\bar\rho_f}\heldfixed{\mc X_f}.
	\label{eq:CN_phase_pressure_definition}
\end{equation}
% AGENT-LOCK-END
Substituting \eqref{eq:CN_component_intrinsic_pressure_definition} into
\eqref{eq:CN_stress_definition} removes the isotropic density-power term, then
solving for the phase Cauchy effective stress as
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\bs\sigma_s'
	=
	\rho_s
	\mbf A_s^{-T}
	\left(
	\left.\p{\psi_s}{\bar{\mbf F}_s^e}\heldfixed{\mc X_s}
	(\bar{\mbf F}_s^e)^T
	\right)
	\mbf A_s^T,
	\qquad
	s\in\mc S .
	\label{eq:CN_pressure_identified_stress}
\end{equation}
% AGENT-LOCK-END
The phase partial Cauchy stress uses the current solid phase density.  The
intrinsic phase stress is the corresponding normalized stress within the solid
phase:
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	\bar{\bs\sigma}_s'
	 & \equiv
	\mbf A_s^{-T}
	\left(
	\bar\rho_s
	\left.\p{\psi_s}{\bar{\mbf F}_s^e}\heldfixed{\mc X_s}
	(\bar{\mbf F}_s^e)^T
	\right)
	\mbf A_s^T .
	\label{eq:CN_intrinsic_component_stress}
\end{align}
% AGENT-LOCK-END
Thus
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\bs\sigma_s'
	=
	\phi_s\bar{\bs\sigma}_s' .
	\label{eq:CN_solid_partial_stress_sum}
\end{equation}
% AGENT-LOCK-END
The distension coefficient gives the tensor restriction
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\bs\sigma_s'
	=
	\rho_s
	\left.\p{\psi_s}{\mbf A_s^e}\heldfixed{\mc X_s}
	(\mbf A_s^e)^T,
	\qquad
	s\in\mc S .
	\label{eq:CN_distension_force_definition}
\end{equation}
% AGENT-LOCK-END

\subsubsection{Solid-volume and fluid-composition restrictions}
At this point the pressure identification
\eqref{eq:CN_component_intrinsic_pressure_definition} has removed the isotropic
density-power term from the true-deformation contribution.  Since the solid
phases have \(\eta_s^s=1\) and their stress-free maps depend on temperature
only, no additional reversible solid-volume-fraction derivative remains.  For
each solid phase volume fraction, the coefficient of \(\phasedot\phi_s\) gives
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	0=
	\lambda+\frac{\pi_s^s}{\phi_s},
	\qquad
	s\in\mc S .
	\label{eq:CN_solid_volume_fraction_restriction}
\end{equation}
% AGENT-LOCK-END
For fluid phases no elastic stress-free dilation term appears, so projecting the
fluid composition coefficient onto the constrained tangent space gives the same
stationarity condition obtained from Hamilton's principle in \eqref{eq:el_eta_all}:
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{empheq}[box=\fbox]{equation}
	\rho_f\left(
	\left.\p{\psi_f}{\eta_f^\beta}\heldfixed{\mc X_f}
	-\left.\p{\psi_f}{\eta_f^N}\heldfixed{\mc X_f}
	\right)
	=
	\frac{\pi_f^\beta}{\eta_f^\beta}
	-\frac{\pi_f^N}{\eta_f^N},
	\qquad
	\beta=1,\ldots,N-1 .
	\label{eq:CN_composition_projected_restriction}
\end{empheq}
% AGENT-LOCK-END

\subsubsection{Entropy restrictions}
The entropy coefficient gives
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	\mathfrak{s}_f
	 & =-\left.\p{\psi_f}{\theta}\heldfixed{\mc X_f},
	\qquad f\in\mc F, \notag                          \\
	\rho_s \mathfrak{s}_s
	 & =-\rho_s
	\left.\p{\psi_s}{\theta}\heldfixed{\mc X_s}
	+\operatorname{tr}\left[
	(\bar{\mbf F}_s^p)^{-1}(\bar{\mbf F}_s^e)^{-1}
	\mbf A_s^{-1}
	(\bs\sigma_s')^T
	\mbf A_s\bar{\mbf F}_s^e\bar{\mbf F}_s^p
	\left.\p{\bar{\mbf F}_s^\theta}{\theta}\heldfixed{\mc X_s}
	(\bar{\mbf F}_s^\theta)^{-1}
	\right]
	\notag                                            \\
	 & \quad
	+\operatorname{tr}\left[
		(\mbf A_s^p)^{-1}(\mbf A_s^e)^{-1}
		(\bs\sigma_s')^T
		\mbf A_s^e\mbf A_s^p
		\left.\p{\mbf A_s^\theta}{\theta}\heldfixed{\mc X_s}
		(\mbf A_s^\theta)^{-1}
		\right],
	\qquad s\in\mc S .
	\label{eq:CN_entropy_definitions}
\end{align}
% AGENT-LOCK-END
The solid entropy relation is phase-level because each mineral phase may have
its own stress-free true-deformation and distension rates.

\subsubsection{Generalized forces and mechanism affinities}
Finally, using \(\phasedot c_\xi^\alpha=\sum_m\nu_{\xi (m)}^\alpha r_{(m)}\), the
source term in \eqref{eq:CN_solid_collected_entropy} becomes
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{align}
	 & -\sum_\xi\sum_\alpha \phasedot c_\xi^\alpha
	\left(\psi_\xi+L_\xi^\alpha\right) \notag \\
	 & \qquad =
	-\sum_m\left[
		\sum_\xi\sum_\alpha\nu_{\xi (m)}^\alpha
		\left(\psi_\xi+L_\xi^\alpha\right)
		\right] r_{(m)} .
	\label{eq:CN_helmholtz_source_projection}
\end{align}
% AGENT-LOCK-END
This term is the open-system source contribution to the entropy inequality.  To
make the entropy production use the same component conversion potential that
appears in the variational stoichiometric constraint, we choose
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	L_\xi^\alpha=\mu_\xi^\alpha-\psi_\xi .
	\label{eq:CN_L_mu_psi_closure}
\end{equation}
% AGENT-LOCK-END
Then \(\psi_\xi+L_\xi^\alpha=\mu_\xi^\alpha\) for every
phase/component source.  The source projection is
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	-\sum_\xi\sum_\alpha \phasedot c_\xi^\alpha\mu_\xi^\alpha
	=
	-\sum_m\left(
	\sum_\xi\sum_\alpha\nu_{\xi (m)}^\alpha\mu_\xi^\alpha
	\right) r_{(m)} .
	\label{eq:CN_mu_source_projection}
\end{equation}
% AGENT-LOCK-END
The mechanism affinity identified by the variational conversion constraint is
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mc A_{(m)}
	= -\sum_\xi\sum_\alpha\mu_\xi^\alpha\nu_{\xi (m)}^\alpha .
	\label{eq:CN_composition_affinity_projection}
\end{equation}
% AGENT-LOCK-END
Substituting the admissible value of \(L_\xi^\alpha\) into
\eqref{eq:el_conversion_component} gives the entropy-admissible conversion
relation
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{empheq}[box=\fbox]{equation}
	\frac{D_\xi\mu_\xi^\alpha}{Dt}
	=
	\frac{1}{2}\mbf v_\xi\cdot\mbf v_\xi
	-\mu_\xi^\alpha
	-\frac{\pi_\xi^\alpha}{\phi_\xi\bar\rho_\xi\eta_\xi^\alpha}.
	\label{eq:CN_admissible_conversion_component}
\end{empheq}
% AGENT-LOCK-END
Thus the source projection \eqref{eq:CN_mu_source_projection} is exactly
the mechanism force power.

\subsubsection{Plastic flow rules and residual dissipation}
The plastic-deformation power in the residual inequality is driven by the
effective stress $\bs{\sigma}^\prime$ of each solid phase mapped through that phase's distension and true-deformation gradients to its plastic-flow configuration.  Because each true-plastic flow is isochoric, only the deviatoric part of that mapped stress
contributes.  Define the deviatoric true-plastic driving stress by
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mbf S_s'
	\equiv
	(\bar{\mbf F}_s^e)^{-1}
	\mbf A_s^{-1}
	\left(
	(\bs\sigma_s')^T
	-\frac{1}{3}\operatorname{tr}\left(\bs\sigma_s'\right)\mbf I
	\right)
	\mbf A_s
	\bar{\mbf F}_s^e,
	\qquad
	s\in\mc S .
	\label{eq:CN_plastic_driving_stress}
\end{equation}
% AGENT-LOCK-END
The trace-free property follows from the similarity transformation of the
deviatoric stress:
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\operatorname{tr}\mbf S_s'
	=0,
	\qquad
	s\in\mc S .
	\label{eq:CN_plastic_driving_stress_trace}
\end{equation}
% AGENT-LOCK-END
This is the direct analogue of Drumheller's
\cite[eqs.~(108)--(112)]{drumheller2000} true-plastic driving stress: his
deviatoric true stress is replaced here by the phase single-primed solid stress
first mapped through that phase's distension tensor.  After the reversible
coefficients have been set to zero, the remaining inequality can therefore be
written as
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\begin{aligned}
		0\le{}\; &
		\sum_m\mc A_{(m)} r_{(m)}
		+\sum_{s\in\mc S}\bs\sigma_s':
		\mbf A_s^e\phasedot{\mbf A}_s^p
		(\mbf A_s^p)^{-1}(\mbf A_s^e)^{-1}                  \\
		         & +\sum_{s\in\mc S}\operatorname{tr}\left[
			\mbf S_s'\phasedot{\bar{\mbf F}}_s^p
			(\bar{\mbf F}_s^p)^{-1}\right]
		+\sum_\xi\rho_\xi e_\xi^{\rm int}
		-\sum_\xi\frac{\mbf q_\xi\cdot\nabla_{\mbf x}\theta}{\theta} .
	\end{aligned}
	\label{eq:CN_residual_dissipation}
\end{equation}
% AGENT-LOCK-END
Admissible reaction kinetics must make \(\sum_m\mc A_{(m)} r_{(m)}\ge 0\),
for example through a closure
\( r_{(m)}=\mc K_{(m)}(\mc A_{(m)},\bs\Lambda)\) with
\(\mc A_{(m)} r_{(m)}\ge 0\) for each independent mechanism.  Following the
same sufficient construction used by Drumheller~\cite{drumheller2000}, one may
choose generic uncoupled flow rules
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{subequations}
	\label{eq:CN_generic_plastic_flow_rules}
	\begin{align}
		\phasedot{\bar{\mbf F}}_s^p(\bar{\mbf F}_s^p)^{-1}
		 & =\Lambda_{\mbf F_s}(\mc X_s)(\mbf S_s')^T,
		\label{eq:CN_generic_plastic_deformation_flow_rule}            \\
		\phasedot{\mbf A}_s^p(\mbf A_s^p)^{-1}
		 & =\Lambda_{\mbf A_s}(\mc X_s)
		(\mbf A_s^e)^T
		\bs\sigma_s'
		(\mbf A_s^e)^{-T},
		\label{eq:CN_generic_plastic_distension_flow_rule}             \\
		\Lambda_{\mbf F_s}(\mc X_s)
		 & \ge0,
		\label{eq:CN_generic_plastic_deformation_mobility_nonnegative} \\
		\Lambda_{\mbf A_s}(\mc X_s)
		 & \ge0,
		\qquad s\in\mc S .
		\label{eq:CN_generic_plastic_distension_mobility_nonnegative}
	\end{align}
\end{subequations}
% AGENT-LOCK-END
with \(\Lambda_{\mbf F_s}(\mc X_s)\) and \(\Lambda_{\mbf A_s}(\mc X_s)\) vanishing in a
neighborhood of elastic equilibrium.  Then the isochoric constraint is preserved
by \(\operatorname{tr}\mbf S_s'=0\), and the two plastic powers in
\eqref{eq:CN_residual_dissipation} are nonnegative term by term.  More general
coupled plastic deformation--distension laws are admissible if their combined
plastic power is nonnegative.

The interphase exchange term can be closed by a pairwise quadratic construction
for reacting porous mixtures~\cite{foster2026reactingporous}.  Following
Bedford and Drumheller~\cite{drumheller1980thermomechanical}, conservation of
energy for the entire mixture requires the internal interaction-energy supplies
and the interphase momentum supplies to satisfy
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\sum_\xi\left(
	\rho_\xi e_\xi^{\rm int}
	+\mbf b_\xi\cdot\mbf v_\xi
	\right)=0 .
	\label{eq:CN_interaction_energy_conservation}
\end{equation}
% AGENT-LOCK-END
Here \(\mbf b_\xi\) is the net interphase momentum supply appearing in the phase
momentum balance.  Decompose it into pairwise interaction forces,
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mbf b_\xi
	=\sum_{\zeta\ne\xi}\mbf b_{\zeta\xi},
	\qquad
	\mbf b_{\zeta\xi}=-\mbf b_{\xi\zeta},
	\label{eq:CN_pairwise_interaction_force}
\end{equation}
% AGENT-LOCK-END
where \(\mbf b_{\zeta\xi}\) is the force exerted on phase \(\xi\) by phase
\(\zeta\).  For each unordered pair, let \(\mbf v_{\xi\zeta}\) denote the
pairwise relative velocity,
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mbf v_{\xi\zeta}=\mbf v_\xi-\mbf v_\zeta .
	\label{eq:CN_relative_pair_velocity}
\end{equation}
% AGENT-LOCK-END
Then \eqref{eq:CN_interaction_energy_conservation} gives
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\sum_\xi\rho_\xi e_\xi^{\rm int}
	=-\sum_{\xi<\zeta}\mbf b_{\zeta\xi}\cdot\mbf v_{\xi\zeta}.
	\label{eq:CN_interaction_power_pairing}
\end{equation}
% AGENT-LOCK-END
A linear dissipative interaction law may be written as
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mbf b_{\zeta\xi}
	=-\mbf k_{\xi\zeta}^{-1}\mbf v_{\xi\zeta},
	\qquad
	\mbf k_{\xi\zeta}=\mbf k_{\xi\zeta}^{T},
	\qquad
	\mbf y\cdot\mbf k_{\xi\zeta}\mbf y>0
	\quad \forall\,\mbf y\ne\mbf 0 .
	\label{eq:CN_interphase_exchange_law}
\end{equation}
% AGENT-LOCK-END
Substitution into \eqref{eq:CN_interaction_power_pairing} gives
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\sum_\xi\rho_\xi e_\xi^{\rm int}
	=\sum_{\xi<\zeta}
	\mbf v_{\xi\zeta}\cdot
	\mbf k_{\xi\zeta}^{-1}\mbf v_{\xi\zeta}
	\ge 0 .
	\label{eq:CN_interphase_exchange_positive}
\end{equation}
% AGENT-LOCK-END
Thus interphase momentum exchange contributes nonnegative entropy production
whenever the tensor $\mbf{k}$ is positive definite.

The heat-conduction term is made admissible by a Fourier-type closure
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	\mbf q_\xi=-\mbf K_\xi\nabla_{\mbf x}\theta,
	\qquad
	\mbf K_\xi=\mbf K_\xi^T,
	\qquad
	\mbf y\cdot\mbf K_\xi\mbf y\ge 0 ,
	\label{eq:CN_heat_flux_closure}
\end{equation}
% AGENT-LOCK-END
with \(\theta>0\).  Then
% AGENT-LOCK-BEGIN equation-lock: do not edit unless explicitly unlocked by user
\begin{equation}
	-\sum_\xi\frac{\mbf q_\xi\cdot\nabla_{\mbf x}\theta}{\theta}
	=
	\sum_\xi
	\frac{\nabla_{\mbf x}\theta\cdot
		\mbf K_\xi\nabla_{\mbf x}\theta}{\theta}
	\ge 0 .
	\label{eq:CN_heat_flux_positive}
\end{equation}
% AGENT-LOCK-END
Equations \eqref{eq:CN_interphase_exchange_positive} and
\eqref{eq:CN_heat_flux_positive}, together with plastic flow rules that make the
plastic part of \eqref{eq:CN_residual_dissipation} nonnegative, are sufficient
to make \eqref{eq:CN_residual_dissipation} thermodynamically admissible.
