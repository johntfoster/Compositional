\section{Material form of conservation of mass}
Given a differential mass ${\rm d}m^\al_\xi$ of component $\al$ in phase $\xi$, define the component partial density per current mixture volume by
%
\[
	\rho^\al_\xi(\mbf{x}, t) = \frac{{\rm d}m^\al_\xi}{\dv},
\]
%
where $\dv = {\rm d}x_1 {\rm d}x_2 {\rm d}x_3$ is a current-configuration volume element of the mixture.  The current configuration is a common mixture volume occupied by all components simultaneously.  Each phase $\xi$ motion is tracked from its own reference coordinates $\mbf{X}_\xi$ and reference volume element
%
\[
	\dVxi = ({\rm d}X_1)_\xi({\rm d}X_2)_\xi({\rm d}X_3)_\xi.
\]
%
The phase reference coordinates are related to the common current coordinates by a one-to-one, invertible, and continuously differentiable map on the region where that phase is present,
%
\[
	\mbf{x} = \bs{\chi}_\xi(\mbf{X}_\xi,t),
\]
%
with phase velocity $\mbf{v}_\xi = \partial \bs{\chi}_\xi/\partial t$ and Jacobian
%
\[
	J_\xi = \det\left(\p{\bs{\chi}_\xi}{\mbf{X}_\xi}\right).
\]
%
Let $\rho_{\xi0}^\al(\mbf{X}_\xi)$ denote the initial (evaluted at $\mbf{x}(t=0) = \mbf{X}_\xi$) component partial density, and let $\mathcal{C}^\al_\xi(\mbf{X}_\xi,t)$ denote the mass of component $\alpha$ added to phase $\xi$ per unit phase reference volume by any internal conversion mechanism.  These mechanisms include both chemical reactions and pure phase transformations.  Conservation of mass for component $\al$ in phase $\xi$ over an arbitrary material region can then be written as
%
% AGENT-LOCK-BEGIN equation-lock: fixed through rendered equation (49); do not edit unless explicitly unlocked by user
\begin{align}
	\int_{\mc{B}_{\xi 0}} \left(\rho_{\xi 0}^\al + \mc{C}^\al_\xi\right)\dVxi
	 & = \int_{\mc{B}} \rho_\xi^\al {\rm d}v
	= \int_{\mc{B}_{\xi 0}} \rho_{\xi}^\al J_\xi \dVxi .
	\label{eq:material_mass}
\end{align}
% AGENT-LOCK-END
%
Here $\mc{B}$ is the common current mixture region corresponding, through the phase-$\xi$ map, to the phase reference region $\mc{B}_{\xi0}$.  Since \eqref{eq:material_mass} must hold for arbitrary $\mc{B}_{\xi0}$,
%
% AGENT-LOCK-BEGIN equation-lock: fixed through rendered equation (49); do not edit unless explicitly unlocked by user
\begin{equation}
	\rho_{\xi 0}^\alpha + \mc{C}^\alpha_\xi = \rho_\xi^\alpha J_\xi.
	\label{eq:material_mass_2}
\end{equation}
% AGENT-LOCK-END
%
The material time derivative of a quantity $\square_\xi$ following the velocity of phase $\zeta$ is
%
\[
	\frac{D_\zeta \square_\xi}{Dt}
	= \frac{\partial \square_\xi}{\partial t}
	+ \mbf{v}_\zeta \cdot\nabla_{\mbf{x}}\square_\xi,
\]
%
and we use the shorthand $\dot\square_\xi = D_\xi \square_\xi/Dt$ for the material time derivative following phase $\xi$.  Taking the material time derivative of \eqref{eq:material_mass_2} following phase $\xi$ and using $\dot{J}_\xi = J_\xi \nabla_\mbf{x}\cdot\mbf{v}_\xi$ gives
%
% AGENT-LOCK-BEGIN equation-lock: fixed through rendered equation (49); do not edit unless explicitly unlocked by user
\begin{align}
	\frac{D_\xi \rho_\xi^\alpha}{Dt}
	+ \rho_\xi^\alpha \nabla_\mbf{x}\cdot\mbf{v}_\xi
	 & = \frac{\dot{\mc {C}}^\alpha_\xi}{J_\xi} .
	\label{eq:component_material_mass}
\end{align}
% AGENT-LOCK-END
%
We define the current production rate per unit current mixture volume by
%
\[
	\dot{c}^\al_\xi(\mbf{x},t) = \frac{\dot{\mc{C}}^\al_\xi}{J_\xi}.
\]
%
Expanding \eqref{eq:component_material_mass} gives the spatial component mass balance of the $\xi$ phase
%
% AGENT-LOCK-BEGIN equation-lock: fixed through rendered equation (49); do not edit unless explicitly unlocked by user
\begin{align}
	\frac{\partial \rho_\xi^\alpha}{\partial t}
	+ \nabla_\mbf{x}\cdot\left(\rho_\xi^\alpha\mbf{v}_\xi\right)
	= \dot{c}^\alpha_\xi .
	\label{eq:component_spatial_mass}
\end{align}
% AGENT-LOCK-END
%
Now introduce the phase partial density $\rho_\xi = \sum_\alpha \rho_\xi^\alpha$ and the mass fraction of component $\alpha$ in phase $\xi$,
%
% AGENT-LOCK-BEGIN equation-lock: fixed through rendered equation (49); do not edit unless explicitly unlocked by user
\begin{equation}
	\eta^\alpha_\xi = \frac{\rho^\alpha_\xi}{\rho_\xi},
	\qquad \sum_\alpha \eta_\xi^\alpha = 1.
	\label{eq:phase_mass_fraction}
\end{equation}
% AGENT-LOCK-END
%
The phase volume fraction is defined by $\phi_\xi = \dv_\xi/\dv$, and the intrinsic density by $\bar\rho_\xi = {\rm d}m_\xi/\dv_\xi$, so that
%
\[
	\rho_\xi = \phi_\xi \bar\rho_\xi,
	\qquad
	\rho_\xi^\alpha = \phi_\xi \bar\rho_\xi \eta^\alpha_\xi.
\]
%
Substituting this representation into \eqref{eq:component_spatial_mass} gives
%
% AGENT-LOCK-BEGIN equation-lock: fixed through rendered equation (49); do not edit unless explicitly unlocked by user
\begin{align}
	\frac{\partial}{\partial t}\left(\phi_\xi \bar\rho_\xi \eta^\al_\xi\right)
	+ \nabla_\mbf{x}\cdot\left(\phi_\xi \bar\rho_\xi \eta^\al_\xi \mbf{v}_\xi\right)
	= \dot{c}^\alpha_\xi .
	\label{eq:spatial_mass_2}
\end{align}
% AGENT-LOCK-END
%
All internal conversion mechanisms are parameterized by current progress rates $\dot r_m$ and phase/component stoichiometric coefficients $\nu_{\xi m}^\alpha$:
%
% AGENT-LOCK-BEGIN equation-lock: fixed through rendered equation (49); do not edit unless explicitly unlocked by user
\begin{equation}
	\dot{c}_\xi^\alpha = \sum_m \nu_{\xi m}^\alpha \dot{r}_m .
	\label{eq:unified_stoich_current}
\end{equation}
% AGENT-LOCK-END
%
The index $m$ includes chemical reactions and pure phase transformations.  A pure phase transformation of component $\alpha$ from phase $\xi$ to phase $\zeta$ is the special one-to-one stoichiometry $\nu_{\xi m}^\alpha=-1$, $\nu_{\zeta m}^\alpha=+1$, with all other entries zero.  A chemical reaction may change both component identity and phase label.  If each mechanism conserves total mass, $\sum_\xi\sum_\alpha\nu_{\xi m}^\alpha=0$, then the overall mixture mass is conserved automatically.  Component conservation is recovered for those pure phase-transformation mechanisms whose stoichiometry has zero sum over phases for the fixed component.
